## v0.8.5 — AI 助手整张专辑歌词上下文（规划已定稿）

> AI 助手「阅读歌词」升级：把「当前播放曲目歌词切片」扩展为「**整张专辑歌词进上下文**」——只要该专辑 `album_lyric` 有歌词（无论是否正在播放、从哪首问起），AI 都能读到整张专辑歌词，按 `tracks_time` 分曲标注《曲名》；歌词与 BPM 在**同一上下文组装步骤**读取（一起进行）。AI 识别/上传后新增的歌词，下次提问自动带上（后端每次现查 `album_lyric`，无需额外同步逻辑）。规划与实现于 2026-08-14。

### 功能概述

1. **整张专辑歌词进上下文**：AI 助手上下文由「当前播放歌曲歌词」（需曲目在播放且传 `current_track_index`）改为「【专辑歌词】」整轨全文——去时间戳、按 `tracks_time` 分曲标注《曲名》（无单曲边界则整轨连续文本，不误标曲目），超长截断 4000 字防上下文爆炸。AI 可回答「第三首歌的歌词表达了什么」等任意单曲问题，不再依赖播放状态。
2. **与 BPM 一起读取**：`_prepare_chat_messages` 在组装上下文时同步读取 `album_tempo`（BPM）与 `album_lyric`（歌词），两段一起进 system prompt。
3. **AI 识别歌词自动同步**：后端每次提问现查 `album_lyric`——初始无歌词 → 无【专辑歌词】段；之后管理员 AI 识别/上传歌词落库 → 下一次提问自动带上，前端/后端无需任何额外同步逻辑。

### 已定决策（2026-08-14 拍板）

| 决策点 | 结论 |
|--------|------|
| 歌词范围 | **整张专辑歌词都进上下文**（用户拍板）；不依赖播放状态，AI 可答任意单曲歌词问题 |
| 是否保留当前曲目切片 | **不保留**——整专歌词是当前曲目切片超集，删除冗余切片逻辑与 `current_track_index` 传参 |
| 分曲标注 | 有 `tracks_time` → 按边界分曲标注《曲名》（无曲名用「单曲N」）；无边界 → 整轨连续文本（不误标） |
| 截断 | `_ALBUM_LYRIC_CAP = 4000`，保留开头（防上下文爆炸） |
| tracks_time 来源 | 优先用户私有副本 `albums_{user_id}.tracks_time`（可能编辑过），回退 `album_pool.tracks_time` |

### 数据来源

| 数据 | 存哪 | 现成 or 需新建 | 查询接口 / 字段 |
|------|------|--------------|----------------|
| 整张专辑歌词 | `album_lyric.lyric_text`（整轨绝对时间存储） | 现成 | `_get_album_lyric` 现查 + `format_album_lyric` 分曲 |
| 单曲边界 tracks_time | `albums_{user_id}.tracks_time` / `album_pool.tracks_time` | 现成 | `_get_album_context` 池 SELECT 补列 |
| BPM | `album_tempo` | 现成 | `_get_tempo` + `format_tempo`（与歌词同一步读取） |

### 架构设计

- **纯函数**：`ai_context.py` 新增 `format_album_lyric(lyric_text, tracks=None, tracks_time=None)`——`lrc.parse_any_to_items` 解析 + `lyric_recognizer.split_by_tracks_time` 分曲 + 逐曲标《曲名》+ `_truncate` 截断 4000；`build_system_prompt` 段落【当前播放歌曲歌词】→【专辑歌词】，参数 `current_lyric_text`→`album_lyric_text`
- **后端组装**：`ai.py` `_prepare_chat_messages` 移除 `current_track_index` 参数，无条件 `_get_album_lyric` 现查 `album_lyric` + `format_album_lyric` 组装，与 `format_tempo`（BPM）同一函数内读取；`_get_album_context` 池 SELECT 补 `tracks_time` 列（无用户副本时回退）
- **前端清理**：`AlbumAIAssistant.vue` 移除 `currentTrackIndex` prop 与 chat body `current_track_index` 字段；`AlbumDetail.vue` 移除对该组件的 `:current-track-index` 绑定（`currentTrackIndex` data 保留，PlayerPlaylist/AlbumLyricViewer 仍用）

### 难点与对策

- **整专歌词超长**：4000 字截断保留开头；有 tracks_time 时按曲分块，即使截断也保住前几首完整曲目块
- **不误标曲目**：无 tracks_time 边界时不标「单曲1」，直接整轨连续文本（避免整轨被当成单曲1）
- **同步无需额外逻辑**：后端每次提问现查 `album_lyric`，AI 识别/上传落库后下次提问天然带上（realdata 测试锁定）
