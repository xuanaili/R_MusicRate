# 项目概述与版本历史

## 项目简介

MusicRate 是一个音乐专辑评分与发现的 Web 应用。用户可以给专辑打分、写听后感、管理播放列表、上传音频文件，以及通过标签/气泡图探索音乐。界面以中文为主，风格标签格式为 `English【中文】`。

## 数据库Schema来源

从 `.idea/dataSources/` 中的IDE数据源模型可确认：
- MySQL 8.0.44，数据库 `music_rate`，排序规则 `utf8mb4_unicode_ci`
- 共享表：`album_comments`、`album_lyric`、`album_pool`、`album_share`、`album_singers`、`album_tags`、`user_album_intro`、`user_album_relation`、`user_playlist`、`user_recommend`、`users`
- 用户分表：`albums_1`、`albums_2`、`albums_3`、`albums_7`、`albums_8`、`albums_9`（按user_id分表）
- `album_comments` 有外键约束（`album_id → album_pool.id`、`user_id → users.user_id`），ON DELETE CASCADE
- `user_recommend` 有外键约束（`user_id → users.user_id`、`recommend_daily_id → album_pool.id`），ON DELETE/UPDATE CASCADE
- IDE中DB Navigator连接用户：`music_user@localhost`
